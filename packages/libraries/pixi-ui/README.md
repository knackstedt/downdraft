# `@downdraft/library-pixi-ui`

PixiJS UI overlay — worker-hosted PixiJS GUI on an OffscreenCanvas layered above the game canvas (legacy game UI; prefer core/imui).

## Install

```sh
bun add @downdraft/library-pixi-ui
```
