# `@downdraft/library-marching-cubes`

Marching-cubes surface extraction — CPU/GPU isosurface meshing for voxel and density-field terrain (MarchingCubesLib descriptor).

## Install

```sh
bun add @downdraft/library-marching-cubes
```
