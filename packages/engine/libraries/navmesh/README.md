# `@downdraft/engine/libraries/navmesh`

Runtime navmesh generation and queries — grid/tiled navigation meshes with path solving and debug visualization.

## Install

```sh
bun add @downdraft/engine/libraries/navmesh
```

## Key exports

- `CrowdSystem`
- `NavAgent`
- `NavMesh`
- `NavMeshDebugViz`
- `NavMeshGenerator`
- `NavmeshLib`
- `NavmeshTok`
- `Pathfinder`
- `PathfinderTok`

See the [Downdraft engine repository](https://github.com/knackstedt/downdraft) for architecture docs and examples.
