# `@downdraft/engine/libraries/weather`

Weather state simulation — fronts, precipitation, and environmental conditions as sim-side state.

## Install

```sh
bun add @downdraft/engine/libraries/weather
```

## Key exports

- `DEFAULT_WEATHER_CONFIG`
- `WeatherBlend`
- `WeatherLib`
- `WeatherSystem`
- `WeatherTok`
- `WeatherType`

See the [Downdraft engine repository](https://github.com/knackstedt/downdraft) for architecture docs and examples.
