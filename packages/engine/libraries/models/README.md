# `@downdraft/engine/libraries/models`

Model loading and mesh pipeline — GLTF/GLB/FBX/PLY/OBJ codecs, normalization, skinning, morph targets, and material adaptation.

## Install

```sh
bun add @downdraft/engine/libraries/models
```
