# `@downdraft/engine/modules/electron-osr`

Electron off-screen rendering module — OSR surfaces, shared-texture transfer, and paint routing for embedded/headless rendering.

## Install

```sh
bun add @downdraft/engine/modules/electron-osr
```

## Key exports

- `BillboardMode`
- `ElectronOSRModule`
- `OSRInputRouter`
- `OSRManager`
- `OSRSABRingBuffer`
- `OSRTextureReceiver`
- `OSRTextureReceiverManager`
- `WorldSpaceUIPass`

See the [Downdraft engine repository](https://github.com/knackstedt/downdraft) for architecture docs and examples.
