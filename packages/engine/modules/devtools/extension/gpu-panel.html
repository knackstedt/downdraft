External Tools (require manual launch)

          

            

              
RenderDoc (Vulkan frame capture)

              
Since Dawn renders via Vulkan on Linux, RenderDoc captures individual frames from the Vulkan backend. Fastest path to "why is this draw call expensive" — pipeline state, texture sizes, redundant passes, overdraw all show up per-frame.

              
Launch RenderDoc, then inject into the Electron renderer process

            

            

              
NVIDIA Nsight Graphics

              
Deeper GPU-side metrics (SM occupancy, memory bandwidth, shader stalls) than RenderDoc. Worth it once RenderDoc tells you which pass is the problem and you need to know why at the hardware level.

              
Launch Nsight Graphics, connect to the Vulkan process

            

            

              
NVIDIA Nsight Systems

              
Timeline view across CPU and GPU. Useful for spotting sync stalls or redundant work caused by Electron's multi-process model (e.g. compositor process doing unexpected work).

              
nsys profile <your-app-launch-command>
