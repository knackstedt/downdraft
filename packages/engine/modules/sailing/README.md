# `@downdraft/engine/modules/sailing`

Sailing mechanics module — wind state, buoyancy integration, and sail controls for nautical apps.

## Install

```sh
bun add @downdraft/engine/modules/sailing
```

## Key exports

- `SailingConfig`
- `SailingStateTok`
- `WindStateTok`
- `createSailingModule`

See the [Downdraft engine repository](https://github.com/knackstedt/downdraft) for architecture docs and examples.
