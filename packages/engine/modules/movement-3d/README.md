# `@downdraft/engine/modules/movement-3d`

3D movement module — character motor, capsule locomotion, and physics-backed movement.

## Install

```sh
bun add @downdraft/engine/modules/movement-3d
```

## Key exports

- `CharacterMotor3DTok`
- `Movement3DConfig`
- `Movement3DStateTok`
- `angleDelta`
- `createCharacterMotor3D`
- `createMovement3DModule`
- `headingBasis`

See the [Downdraft engine repository](https://github.com/knackstedt/downdraft) for architecture docs and examples.
