# `@downdraft/asset-bake`

Offline asset baking pipeline — converts and optimizes meshes, textures, and shaders into engine-ready formats at build time.

## Install

```sh
bun add @downdraft/asset-bake
```

## Key exports

- `BAKE_CONFIG_VERSION`
- `BakeCache`
- `DEFAULT_BAKE_OPTIONS`
- `bakeAsset`
- `bakeAssetFromBytes`
- `bakeAudio`
- `bakeGltf`
- `resolveOptions`

See the [Downdraft engine repository](https://github.com/knackstedt/downdraft) for architecture docs and examples.
