# `@downdraft/module-movement-2d`

2D movement module — grid character controller and tile-based locomotion with DI tokens.

## Install

```sh
bun add @downdraft/module-movement-2d
```

## Key exports

- `GridCharacterControllerTok`
- `Movement2DConfig`
- `Movement2DStateTok`
- `createGridCharacterController`
- `createMovement2DModule`

See the [Downdraft engine repository](https://github.com/knackstedt/downdraft) for architecture docs and examples.
